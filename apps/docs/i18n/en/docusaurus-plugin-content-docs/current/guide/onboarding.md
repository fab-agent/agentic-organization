# AI Setup

Instead of entering departments, people, agents, skills and policies one by one, an AI assistant sets them up by talking with you. It is the fastest start for a new company.

**Prerequisite:** at least one active AI provider key ([Settings](/guide/settings#ai-providers)). **Where:** **Settings → Set Up with AI** (an invitation appears in Settings for companies that have not been set up yet).

## Four phases

1. **Research.** The system researches your company name on the web and keeps what it finds as context.
2. **Conversation.** The assistant asks 3 to 5 targeted questions about your team size, recurring workflows, the tools you use and data sensitivity. When it has enough information it asks "shall the organization structure be created?"; you can choose **Keep talking** if you like, or **Generate Structure** to move on to the preview.
3. **Preview.** Everything to be created is listed first: departments, people, agents, skills, policies. **Nothing has been saved yet.** You can approve or go back to the chat.
4. **Creation.** When you press **Records to Create**, all records are written in a single transaction. Skills arrive with full Markdown content.

You can skip the setup with **Skip**.

## If it is interrupted

Even if the browser closes or the connection drops, progress is saved. When you come back you continue from where you stopped (if you were at the preview phase, the structure is still ready).

## Afterwards

Review and edit the resulting structure on the **Structure** and **Organization** pages. Do not forget to [invite people](/guide/people-and-access): the setup creates human personnel records but does not open platform accounts.
