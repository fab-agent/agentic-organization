# fab.engineering

**Self-hosted, Open-Source**-Plattform für Unternehmen, die KI-Agenten strukturiert verwalten möchten.

Weisen Sie jedem Mitarbeiter einen KI-Agenten zu, verwalten Sie Richtlinien und Fähigkeiten über YAML-Dateien und visualisieren Sie das Organigramm.

---

## Kernkonzepte

| Konzept | Beschreibung |
|---|---|
| **Unternehmen** | Oberste Organisationseinheit. Mehrere Unternehmen können verwaltet werden. |
| **Abteilung** | Team/Einheit, die einem Unternehmen zugeordnet ist. Enthält Ziele und eine Richtlinienliste. |
| **Personal** | Menschlicher Mitarbeiter oder Agent. Beide erscheinen in der gleichen Hierarchie. |
| **Agent** | KI-Konfiguration, die einem Mitarbeiter zugewiesen ist (Modell + Skills + Status). |
| **Skill** | Eine Fähigkeitsdefinition für einen Agenten (Name, Version, Beschreibung). |
| **Plattform-Benutzer** | Ein Mensch, der sich mit E-Mail + Passwort anmeldet. Wird per Einladung hinzugefügt. |
