# Inbox

The Inbox is the central messaging area where all platform notifications and automation results are collected. Autonomous flow outputs, task notifications, and system messages are all listed here.

---

## Access

All roles can access the **Inbox** (`/inbox`) page. It opens via the **Inbox** menu item in the left sidebar.

---

## Message Types

| Type | Icon Color | Description |
|---|---|---|
| `flow` (Flow) | Purple | Result of an autonomous flow run |
| `task_request` (Task) | Blue | New task assignment notification |
| `task_result` (Result) | Green | Output of a completed task |
| `system` (System) | Blue | System messages generated by the platform |

Unread messages are indicated in the list with a blue dot and bold text. The **new** badge in the top-right shows the count of unread messages.

---

## Auto-Refresh

The Inbox refreshes messages in the background **every 30 seconds**. As long as the page is open, new notifications appear automatically — no manual refresh required.

---

## Filtering and Search

Use the filter bar to narrow messages by time range:

| Filter | Shows |
|---|---|
| **All** | All messages |
| **This week** | Last 7 days |
| **This month** | Last 30 days |

Use the **Unread only** button to list only unread messages.

---

## Message Actions

### Open / Collapse a Message

Clicking a message row expands the full content below it. The message is automatically marked as **read** on click.

### Mark All as Read

The **Mark All as Read** button, visible in the header when there are unread messages, marks all messages as read at once.

### Delete

The trash icon to the right of each message permanently deletes it. Deletion cannot be undone.

---

## Tasks Awaiting Your Approval

Task requests assigned to you that have not yet been acted upon are highlighted in a separate section above the message list with a yellow background.

Each pending task card shows:

- **Task title and description**
- **Note field** — optional; for providing context when running or rejecting the task
- **Run** — Executes the task via the LLM API; the result is delivered to the Inbox of the person who created the request
- **Reject** — Rejects the task; a notification is sent to the person who created the request

For more information about Task Requests, see → [Task Requests](./task-requests.md)

---

## Creating a Task Request

The **Task Request** button in the header opens a new task request form. The form can be used directly from the Inbox page. For details, see → [Task Requests](./task-requests.md)

---

## API Endpoints

| Endpoint | Method | Description | Permission |
|---|---|---|---|
| `/inbox?company_id=` | GET | Message list (filtered) | `user+` |
| `/inbox/{id}/read` | POST | Mark message as read | Message owner |
| `/inbox/read-all?company_id=` | POST | Mark all as read | `user+` |
| `/inbox/{id}` | DELETE | Delete message | Message owner |
