# Our Policy and Guardrail Approach

The **Policy** (Guardrail) system is critical for ensuring agents operate safely and in a controlled manner.

## Policy Types

We define three core policy types in our system:

### 1. Content Policy
Defines content restrictions. For example:
- Blocking sensitive data sharing
- Preventing leakage of personal information
- Prohibited words and topics

### 2. Behavior Policy
Determines behavioral rules. For example:
- Always responding in a polite and professional manner
- Saying "I don't know" in ambiguous situations
- Building empathy with the customer

### 3. Access Policy
Defines access restrictions. For example:
- Access limited to specific department data
- Authorization to use specific MCP tools
- Time-based access restrictions

## Policy and Agent Relationship

Multiple policies can be assigned to each agent. Policies can also restrict an agent's use of skills.

Example:  
*"Agents in the Finance department can only use Finance MCP tools."*

This approach both increases security and clarifies the scope of authority for agents.
