# MCP Tools and Skill Development Process

**Skills** — which enable Agents to interact with the real world — are one of the most critical components of our system.

## Skill Types

| Type      | Description                                   | Example |
|-----------|-----------------------------------------------|---------|
| Function  | Functions defined in code                     | PDF generation, sending emails |
| MCP       | Model Context Protocol tools                  | Google Search, Slack, Odoo integration |
| Custom    | User-defined custom tools                     | Company-specific business processes |

## Skill Development Flow

1. **Personnel** identifies a new need.
2. Develops the Skill through the Personnel Portal.
3. Tests the Skill.
4. Sends a **publishing request** to the Admin.
5. Admin reviews the request from the MCP Tool Requests screen.
6. Approved Skills are added to the system and can be assigned to Agents.

## MCP Tool Requests

MCP tool requests submitted by Personnel are managed through a dedicated screen in the Admin Panel. Through this screen:

- Request details are reviewed
- Security and compliance checks are performed
- Approval / Rejection decisions are made

This process both meets the needs of Personnel and preserves organizational control.
