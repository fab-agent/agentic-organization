# fab.engineering

Plataforma **self-hosted y open-source** para que las empresas gestionen agentes de IA de forma estructurada.

Asigna un agente de IA a cada miembro del personal, gestiona políticas y habilidades mediante archivos YAML y visualiza el organigrama.

---

## Conceptos Clave

| Concepto | Descripción |
|---|---|
| **Empresa** | Unidad organizativa de nivel superior. Se pueden gestionar varias empresas. |
| **Departamento** | Equipo/unidad vinculado a una empresa. Contiene objetivos y una lista de políticas. |
| **Personal** | Empleado humano o agente. Ambos aparecen en la misma jerarquía. |
| **Agente** | Configuración de IA asignada a un miembro del personal (modelo + habilidades + estado). |
| **Habilidad** | Definición de capacidad de un agente (nombre, versión, descripción). |
| **Usuario de Plataforma** | Un humano que inicia sesión con email + contraseña. Se añade mediante invitación. |
