# Agent Sistemi Nasıl Kullanılır?

Bu bölümde Hermes Agent ve 3rd Party Agent Organization sisteminin nasıl kullanılacağı anlatılmaktadır.

## Temel Kavramlar

- **Organization**: Şirket veya ekip yapısı
- **Personnel**: Organizasyon içindeki kişiler
- **Agent**: Her personele atanabilen AI asistanı

## Temel Akış

1. Organizasyon oluştur
2. Personel ekle
3. Her personele agent tanımla
4. Policy ve skill dosyalarını yönet
