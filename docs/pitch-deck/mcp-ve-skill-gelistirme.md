# MCP Araçları ve Skill Geliştirme Süreci

Agent'ların gerçek dünya ile etkileşime girmesini sağlayan **Skill**'ler, sistemimizin en kritik bileşenlerinden biridir.

## Skill Türleri

| Tür       | Açıklama                                      | Örnek |
|-----------|-----------------------------------------------|-------|
| Function  | Kod ile tanımlanmış fonksiyonlar              | PDF oluşturma, e-posta gönderme |
| MCP       | Model Context Protocol araçları               | Google Search, Slack, Odoo entegrasyonu |
| Custom    | Kullanıcı tanımlı özel araçlar                | Şirkete özel iş süreçleri |

## Skill Geliştirme Akışı

1. **Personel** yeni bir ihtiyaç tespit eder.
2. Personnel Portal üzerinden skill geliştirir.
3. Skill'i test eder.
4. Admin'e **yayınlama talebi** gönderir.
5. Admin, MCP Araç Talepleri ekranından talebi inceler.
6. Onaylanan skill sisteme eklenir ve agent'lara atanabilir.

## MCP Araç Talepleri

Personelden gelen MCP araç talepleri, Admin Panel'deki özel bir ekrandan yönetilir. Bu ekran sayesinde:

- Talep detayları incelenir
- Güvenlik ve uyumluluk kontrolü yapılır
- Onay / Red kararı verilir

Bu süreç, hem personelin ihtiyaçlarını karşılar hem de organizasyonun kontrolünü korur.
