# Fab Agent Dokümantasyonu

Fab Agent organizasyonunun resmi dokümantasyon sitesi.

Bu site şu amaçlarla kullanılmaktadır:

- **Agent Sistemi Kullanımı**: Hermes Agent ve 3rd Party Agent Organization'ın nasıl kullanılacağı
- **Pitch Deck**: Yatırımcılara ve iş ortaklarına yönelik sunum içerikleri
- **API Dokümantasyonu**: Teknik API referansları ve entegrasyon kılavuzları
- **Mimari ve Kararlar**: Sistem mimarisi, tasarım kararları ve sorun-çözüm notları

## Hızlı Başlangıç

```bash
git clone https://github.com/fab-agent/docs.git
cd docs
npm install
npm start
```

Site `http://localhost:3000` adresinde açılır.
